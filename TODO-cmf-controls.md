# Управление CMF Buds Pro 2

Отложено. В правой панели Caelestia рядом с Quick toggles нужна кнопка наушников.

- [ ] По нажатию открывать отдельное всплывающее окно в стиле встроенных настроек Caelestia.
- [ ] Показывать заряд L / R / C и переключатели ANC / Transparency / Off. Остальные настройки определить позже.
- [ ] Проверить команды на реальных наушниках и отображать фактическое состояние; недоступные данные — «—».

Уже есть чтение заряда: `hypr-lua/scripts/cmf-battery.py` и патч `0058-bluetooth-cmf-separate-battery.patch`.
Протокол: [CMF Control](https://github.com/JScoder4005/cmf-control), RFCOMM Nothing/CMF. Управляющие команды ещё не проверены.
Оформлять изменения патчем в `patches/caelestia/`.

Кейс подтверждён реальным событием `0xE001` (C: 10%); требуется слушать уведомления, а не закрывать RFCOMM после первого ответа. Это исправляет патч `0059-bluetooth-cmf-battery-notifications.patch` и режим `--watch` считывателя.
